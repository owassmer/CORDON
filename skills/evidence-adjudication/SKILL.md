# Evidence adjudication

Keep four epistemic classes explicit:

1. material actually retrieved;
2. facts directly stated by that material;
3. inference or computation from those facts;
4. the adjudicated state adopted for use.

Verify consequential claims against the primary artifact. Recompute headline quantities from the underlying data where feasible. A citation, secondary summary, review report, or confident model statement is not a substitute for retrieval.

Scope completeness to the claim. Enumerate source families capable of falsifying it and record what was examined, unavailable, or outside aperture. Do not demand global omniscience, but do not hide an unexamined falsifier.

When sources conflict, preserve the conflict until authority, time, scope, or an owner ruling resolves it. When evidence is absent but reachable, create an acquisition task. When it is genuinely unavailable, state which conclusion remains blocked.

Admit a source into a system only when it changes, constrains, supplies, or validates a nameable consumer decision. Preserve point-in-time versions when the answer can change with time.

For CORDON, the corpus catalog owns source classification and the canonical stage artifacts own adjudicated meaning; follow [the project navigation](../../AGENTS.md).
