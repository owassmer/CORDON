## Adopt now — compatible with accepted design and lower complexity

1. **One context envelope.** Treat selected object set, route, Action, as-of, Proposal ID, target hash/count, premise fingerprint and context generation as one logical application-state contract. This strengthens D9 and exact tool inputs; no new object.
2. **Semantic Map modes inside the persistent Map pane.** Change footprint, authority context, dispatch scope and outcome footprint control native layer visibility/locking/zoom. This reduces layer-management complexity without collapsing the Map or removing the five responsibility lines Owen explicitly accepted.
3. **Freeze presentation during a consequential command, then revalidate server-side.** Pause scene refresh, capture context generation/fingerprint, submit exact Action, resume after receipt/refusal. No data freeze and no client authority.
4. **Population-scale Function contracts.** Pipelines own complete candidate populations; Functions use indexed/object-set inputs, backend aggregation, pagination and bounded digests. No `.all()` over full CORDON populations.
5. **Source-native change patterns.** True CDC only when the source provides ordering/deletion; ArcGIS/BURP/WFS use snapshot+manifest+diff; external outcomes use authenticated occurrence ingestion. No faux CDC.
6. **Selective Workshop refresh.** Watch Now projections, selected semantic objects and exact linked dependencies; pause during command capture. Do not globally refresh the full graph.
7. **Exact evidence jumps.** Immutable document identity/hash + page/search locator opens native viewer at the relevant basis. No generic Evidence or annotation object.
8. **Model selection by frozen Evals.** Already accepted; report confirms hosted candidates are visible.
9. **Narrow mobile companion.** Already accepted; field scan/location/read/capture/handoff only, no compressed desktop.
10. **Executable-package projection.** Present one package/batch/evidence/liability view assembled from existing Holdings, Parcels, Instruments, Proceedings, Interventions, Parties, histories and capacity. Do not add a generic Package object until direct OP evidence proves independent identity/lifecycle.

## Probe before adoption

1. **Plant Trade Unit / Lot semantic reopening.** Primary sources verify three-year lot/recipient traceability and passport/cadastral destination requirements. Both domain/data reports independently identify lot identity as operationally load-bearing across supplier, cultivar, passport, allocation, substitution, warranty and replacement. This is a real challenge to Gate 5's conditional exclusion. Before reopening, acquire one actual nursery procurement/delivery/warranty pack from an OP/provider and test whether Intervention material history can preserve split allocations, substitutions, recalls and warranty across multiple Interventions. If not, admit `PlantTradeUnit` and evaluate an exact Allocate/Substitute Action. This is an Owen-level semantic decision.
2. **Scenario merge versus custom staged writes.** Probe whether Apply Scenario can preserve CORDON revalidation, idempotency, occurrence and receipt contracts with less code. Reject if it needs a parallel edit plan or second transaction.
3. **Action log + occurrence as receipt backbone.** Probe whether the exact durable receipt can be reconstructed after response loss. Keep a focused receipt store only if generated logs omit required binding/non-implication fields.
4. **Native capacity comparison before custom widget.** Try table/chart/metric comparison and immutable Proposal first. Add the one allowed custom widget only for a measured native gap.
5. **AdE WFS as current cadastral source.** B1.1 SIT remains a dated 2021 source. Probe native WFS full-region extraction and identifier reconciliation; if it succeeds, make AdE current geometry primary and SIT a dated reconciliation vintage.
6. **Sample identity across services/vintages.** Full-load evidence determines whether ID_CAMPIONE is globally unique; namespace by service/campaign if not.
7. **Existing OP systems integration.** Direct PugliaOlive evidence may show CRM/AgroAPP/traceability/accounting systems that make CORDON a governed decision overlay rather than a system-of-record replacement.

2. **Responsibility facets replacing persistent lines.** Same reason. Facets may be supplemental filters, not the primary representation.
3. **Make capacity the product hero.** Owen corrected this: capacity comparison/reallocation is a bounded feature. Keep a deterministic comparison and exact Action where scarcity creates a real decision, but choose the intuitive native implementation and do not let Scenario, optimizer, Proposal, or receipt mechanics dominate the sprint.
4. **Universal correspondence/task system.** Direct evidence is absent; integrate existing CRM/email where possible or later add bounded cure commitments, never generic Task/Queue objects.
5. **Expand to mill/market operations.** Only admit a downstream compatibility premise where it materially changes Intervention design or feasibility; Wedge 1 does not become commercial operations.
6. **Make refusal/INDETERMINATE central.** Already rejected by Owen; these remain behaviors/Eval cases.
